# Mexico Toy Sales Analysis | Power BI Dashboard

## 📊 Project Overview

This project analyzes toy sales data from Mexico to understand sales performance, profitability, product performance, and store performance.

The dashboard was built using Microsoft Power BI and Excel to transform raw sales data into clear and useful business insights.

## 🎯 Business Questions

- What is the total revenue and profit?
- Which product categories generate the highest revenue?
- Which products are the most profitable?
- Which stores perform better?
- What is the overall profit margin?
- How many units were sold?

## 📈 Key KPIs

| KPI | Value |
|---|---:|
| Total Revenue | 14.44M |
| Total Profit | 4.01M |
| Total Units Sold | 1M |
| Profit Margin | 27.79% |

## 💡 Key Insights

- Toys generated approximately 5M in revenue.
- Electronics achieved the highest profit margin at approximately 45%.
- Lego Bricks was among the top products by revenue.
- Colorbuds generated a notably high profit.
- The product with the highest revenue is not necessarily the product with the highest profit.
